# guardunit

Guard CSV/TSV unit tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/guardunit/

## Install / run

```bash
git clone https://github.com/theworker02/guardunit.git
cd guardunit
node src/cli.js
node --test
```
